# モグラ叩き 60秒チャレンジ

スマホで遊べる、1回60秒のモグラ叩きゲームです。HTMLファイル1つだけで動き、インストールは要りません。

## ファイル構成

| ファイル | 内容 |
|---|---|
| `index.html` | ゲーム本体（HTML・CSS・JavaScript） |
| `config.js` | ランキングサーバーの接続情報（Project URL と公開用キー） |
| `supabase/schema.sql` | ランキング用のテーブルと関数 |
| `icon.svg` | アイコンの元データ（`index.html` に埋め込み済み） |

## 遊び方

`index.html` をブラウザで開くと、すぐに遊べます。GitHub Pages で公開すれば、スマホからURLを開くだけで遊べます。

| キャラクター | 内容 |
|---|---|
| 🟤 モグラ | 1回叩くと +10点 |
| 🟡 金モグラ | +50点。出ている時間が短い |
| 👨‍👦‍👦 3兄弟モグラ | 1回叩くごとに1匹ずつ引っ込む。+10 → +20 → +30 で、3匹とも叩くと合計 +60点（コンボ倍率はかからない） |
| 💣 ボム | 叩くと −30点で、コンボも切れる |

- **コンボ**：5回続けて当てるごとに得点の倍率が上がる（最大3倍）
- **ミッション**：ランダムに出るお題を時間内にクリアすると、ボーナス点がもらえる
- **ラストラッシュ**：ミッションを4つクリアすると、残り10秒でラッシュが始まる（モグラが一気に増え、得点は1.5倍）
- **ランク称号**：スコアに応じて8段階の称号がもらえる
- **ベストスコア**：遊んだ端末のブラウザに保存される
- **全体ランキング**：Supabase を設定すると、全員の自己ベストで順位を競える。オフライン中の記録は端末に保留し、あとで自動送信（設定方法は下記）

## 全体ランキング（Supabase）

[Supabase](https://supabase.com)（無料のデータベースサービス）を設定すると、全員の自己ベストで順位を競えます。設定しなくてもゲームは遊べ、自己ベストだけが端末に記録されます。

### しくみ

- 1人1行で**自己ベスト**を競います。ゲームが終わると自動で送信され、サーバーは今より高いときだけ記録を更新します。
- 初回起動時に、端末ごとに「書き込み用の秘密ID」と「表示用の公開ID」を作ります。秘密IDはランキングに出ないので、他人の記録は書き換えられません。ブラウザのデータを消すと、別の人として扱われます。
- ニックネームの初期値は「モグラ」＋4桁の数字です。ランキング画面で変更できます（最大12文字）。
- 送信できないとき（オフラインなど）は端末に「未送信」として残し、オンラインに戻ったときに自動で送ります。オフライン中は、最後に取得したランキングに自分の記録を重ねて表示します。
- 同期するタイミング：起動の1.5秒後／ゲーム終了直後／ランキング画面を開いたとき／ニックネームを変えたとき／ネットに戻ったとき／アプリを前面に戻したとき／未送信がある間は60秒ごと。

### 有効にする手順

1. **プロジェクトを作る**：Supabase でプロジェクトを作ります（無料プランでよい）。リージョンは「Northeast Asia (Tokyo)」がおすすめです。
2. **テーブルと関数を作る**：ブラウザの自動翻訳をオフにしてから、「SQL Editor」に [`supabase/schema.sql`](supabase/schema.sql) を全文貼り付けて「Run」します。「Success. No rows returned」と出れば成功です。翻訳されたままだとSQLが壊れます。
3. **接続情報を入れる**：「Project Settings → API Keys」で Project URL と公開用キー（Publishable key）をコピーし、[`config.js`](config.js) に入れます。まるおゲーム共通の書き方（`MARUO_CONFIG`）をそのまま使えます。

   ```js
   window.MARUO_CONFIG = window.MARUO_CONFIG || {
     SUPABASE_URL: 'https://xxxxxxxx.supabase.co',   // ← 行の最後のカンマを忘れずに
     SUPABASE_KEY: 'sb_publishable_xxxxxxxx'
   };
   ```

   このゲームだけ別のサーバーにしたいときは、`window.MOGURA_CONFIG = { SUPABASE_URL: '…', SUPABASE_ANON_KEY: '…' };` と書けば、そちらが優先されます（キーの項目名は `SUPABASE_KEY` でも `SUPABASE_ANON_KEY` でも可）。

4. **アップロードする**：`config.js` を GitHub にアップロードします。
5. **確認する**：1回遊んで、ランキングに自分の名前が出れば完了です。うまくいかないときは、Supabase の「Logs → API」で確認してください（404：SQL未実行、401：キー違い）。

> ⚠️ `config.js` に入れるのは公開用キー（`sb_publishable_…` または `anon public`）だけです。**秘密のキー（`sb_secret_…`、`service_role`）は絶対に入れないでください。**

### サーバー側（`supabase/schema.sql`）

- 同じ Supabase プロジェクトを他のゲームと共用できるよう、テーブルと関数の名前はすべて `mogura_` で始めています。ラマダッシュなど、他のゲームの `scores` テーブルや関数には触りません。
- テーブル `mogura_scores`：`player_id`（秘密ID）、`pub_id`（公開ID）、`name`（1〜12文字）、`best`（0〜20,000）、`updated_at`
- テーブルへの直接アクセスは禁止です。公開用キーから呼べるのは次の3関数だけです。
  - `mogura_submit_score`：未登録なら追加します。登録済みなら名前は毎回更新し、記録は高いときだけ更新します。範囲外の記録、空や13文字以上の名前、形式違いの公開IDは拒否します。
  - `mogura_get_leaderboard`：記録の高い順に上位を返します（既定50件、最大100件）。同点は先に記録した人が上です。
  - `mogura_get_rank`：その記録より高い人数＋1を返します。
- このゲームの最初の版（1プレイ1行）の `scores` テーブルがある場合は、消さずに `mogura_scores_old_v1` という名前で退避します。

### 更新・運用するとき

- ゲームを更新するときは、変更したファイルだけを上書きアップロードしてください。**キー入りの `config.js` を、空のもので上書きしないよう注意してください。**
- ブラウザだけで動く仕組みなので、詳しい人による偽スコアの送信は完全には防げません。他人の記録は書き換えられず、極端な値はサーバーが拒否します。怪しい記録は「Table Editor」の `mogura_scores` から削除できます。
- Supabase の無料プランは、1週間アクセスがないと一時停止します。停止中もゲームは遊べ、自己ベストは端末に保留され、管理画面から再開したあとに送信されます。

## バランス調整

`index.html` の `<script>` の最初にある `CONFIG` の数字を変えると調整できます。

| 項目 | 内容 |
|---|---|
| `duration` | プレイ時間（秒） |
| `spawnInterval` / `upTime` / `maxActive` | モグラが出る間隔・出ている時間・同時に出る最大数（開始時 → 終了時） |
| `rates` | 金モグラ・ボム・3兄弟モグラの出やすさ |
| `points` | それぞれの点数 |
| `comboStep` / `comboMaxMult` | コンボ倍率が上がる間隔と上限 |
| `rushNeed` / `rushSeconds` / `rush` | ラッシュに必要なミッション数、始まるタイミング、ラッシュ中の設定 |
| `ranks` | 称号と、もらえる点数 |

ミッションの種類は、`MISSIONS` の配列で追加・変更できます。

## 技術メモ

- 外部ライブラリは使っていません（HTML・CSS・JavaScriptのみ。フォントは Google Fonts から読み込み）
- ランキングは Supabase の REST API（`/rest/v1/rpc/<関数名>`）を `fetch` で直接呼んでいます（タイムアウト8秒、キャッシュなし）
- キャラクターはすべて SVG で描いたオリジナルです
- 効果音は Web Audio API で、その場で生成しています
